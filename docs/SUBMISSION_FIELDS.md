# Portal submission fields

Replace each placeholder only after logged-out validation.

## Public GitHub Repository Link

```text
https://github.com/YOUR_USERNAME/carboncue
```

## Deployed Link

Use the direct evaluator route in the portal unless the rules prohibit query parameters:

```text
https://YOUR_DEPLOYMENT.vercel.app/?demo=1
```

Fallback base URL:

```text
https://YOUR_DEPLOYMENT.vercel.app/
```

## LinkedIn Post

```text
https://www.linkedin.com/posts/YOUR_PUBLIC_POST_SLUG
```

## Final validation

- Open every URL in a logged-out browser.
- Confirm the GitHub repository is public and has only `main`.
- Confirm the direct deployment displays the fictional-data banner.
- Confirm the LinkedIn audience is **Anyone**.
- Confirm the deployed commit matches the latest commit on GitHub.
